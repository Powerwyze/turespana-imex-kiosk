# Client clothing reference

The client supplied a six-panel clothing sheet for Canarias, Barcelona, Bilbao, Madrid, Andalucía and Valencia. It is bundled privately as assets/costume-reference.jpg and sent as the third image to the portrait service. Each destination selects its labelled panel. The sheet guides garments, fabrics and layering, not the models’ identities, poses or photographic rendering. Existing illustrated style, source-face/hair preservation and foreground-person checks remain authoritative. Headwear is optional and must not obscure the captured guest.

The second client image guides the kiosk’s Spain-themed background illustration. It does not replace the established portrait-rendering style or add reference people to guest photos.
